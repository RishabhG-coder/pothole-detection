🛣️ Real-Time Pothole Detection using YOLOv8

A real-time pothole detection system built using YOLOv8 and OpenCV to identify road damages from images, videos, and webcam feeds.

✨ Features

Detects potholes in real-time
Works on images, videos, and webcam
Displays bounding boxes with confidence scores
Uses confidence thresholding to reduce false positives

🛠️ Tech Stack

Python
YOLOv8
PyTorch
OpenCV
NumPy
